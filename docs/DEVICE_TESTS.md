# Android acceptance checks

These checks require an Android device or emulator. Unit/widget tests do not prove hardware behavior.

1. Install the APK, enable airplane mode, launch without an account, import a known-good MP3 through the system picker, and play it. Check parsed tags, duration, artwork, local search, and duplicate import handling.
2. Pause, seek, skip, shuffle, and cycle repeat off/all/one. Create a queue containing the same song twice; move and remove entries before/after the active item. Reopen the app and check that it restores paused at the last saved position. Clear the queue and verify that headset/widget Play does not restart an old track.
3. Lock the screen for five minutes. Check continued playback, media notification, lock-screen controls, Bluetooth buttons, audio interruption/resumption, and headphone-unplug pause. Check Android battery restrictions on the actual phone.
4. Favorite songs, listen past the history threshold, create/rename/reorder/delete playlists, and reorder/remove their tracks. Force stop and reopen. Verify persistence and that deleting a playlist keeps its audio.
5. Open Glyph Music once, then check populated wide (4×2), square (2×2), and tall (2×4) previews. Add each widget and resize between shapes. Check artwork, title, artist, and previous/play-pause/next controls. The widgets should have no white outline and no tall-layout brand label. Pause playback, swipe away the app or kill its background process, and tap widget Play: it should launch Glyph, restore the queue, and play. Verify previous/next and tall queue/playlist shortcuts. Remove and re-add widgets if old previews are cached. Android 15+ system Force stop disables widgets until the app is manually reopened; this differs from swiping away or ordinary process death. See [Android stopped-state behavior](https://developer.android.com/about/versions/15/behavior-changes-all#stopped-state).
6. Switch light/dark/system themes; test system text scaling at 100%, 150%, and 200%, TalkBack, landscape, and narrow screens. Launcher widgets use a translucent smoked surface over the wallpaper.
7. Import a broken MP3, cancel the picker, deny a folder grant, remove a managed file using device debugging, and simulate low storage. Ensure failure messages leave the existing library usable. Folder path access varies by Android document provider; individual file import is the baseline.
8. Without a proxy configured, search YouTube for phrases containing punctuation and non-English text. Check results stay in Glyph Music and show Download. Download permitted test audio, verify progress, cancel/retry, and a completed playable local track with matching title/channel/artwork. Repeat the same result and verify deduplication. Test unavailable/restricted videos and source HTTP 403: the error must be visible, the partial file removed, and no incomplete track added. Check recent history, local search, airplane-mode playback of completed downloads, and the optional external-video button. Version 1.3's compatibility client passed a full 10,271,496-byte Blender audio transfer on the PC connection; test the native download/import/playback flow separately. Test the optional discovery proxy separately.
9. Download a permitted original MP3 over HTTPS. Check progress, cancel, retry, duplicate detection, incomplete response, oversized response, HTML disguised as MP3, and HTTPS-to-HTTP redirect rejection. Unknown-size downloads reserve a conservative 500 MB plus import-copy space. No pause/resume or transcoding is claimed.
10. Export metadata, reimport the original audio into a fresh library, restore the backup, and check favorites/playlist order/settings. Audio and artwork are not embedded in metadata backups.
11. Delete a library entry with and without file deletion. Check the confirmation and original-source preservation. Before testing all-data deletion, export backups and copies of app-managed audio.
12. Profile startup, scrolling, search, import, memory, battery, and playback with a 10,000-track library on a representative phone. The source includes a 10,000-track search correctness test; it is not a device performance certification.
13. Open Glyph and allow audio access. Check indexed MP3/M4A/FLAC/WAV/OGG and short recordings appear in Library without copying originals. Search/play a discovered track, add it to a playlist, rename/favorite it, reopen and manually rescan: no duplicates or lost edits/membership. Add/remove a shared audio file outside Glyph and rescan; managed imports/downloads must remain intact. Deny/revoke audio access and retry; the existing library must remain and permission guidance must be visible. Check SD-card audio where available. Files in another app's private storage or excluded from MediaStore are outside the scan scope.

Use a private release signing key for release distribution; the debug APK is for development/personal testing.
